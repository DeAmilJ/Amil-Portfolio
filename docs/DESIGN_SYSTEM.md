# Amil Portfolio Design System

## Vision

An editorial-inspired portfolio that feels like a curated museum exhibition.

The portfolio should communicate strategic thinking, strong taste, and visual storytelling.

---

## Core Principles

1. Scroll first.
2. Contents is the only flat section.
3. Every other section uses depth, layering, texture, and scale.
4. Imagery should be large and bold.
5. Typography creates hierarchy.
6. Interactions must support the story.
7. Every project introduces its own visual identity.
8. Avoid unnecessary clicking.
9. Every section should have one memorable hero moment.
10. Nothing should feel like a template.

---

## Site Structure

- Cover
- Contents
- Mïmïk Moon
- Love Bite
- Journal
- About
- Contact

One continuous scrolling experience.

---

## Archive Reel

Each project includes an Archive Reel.

Desktop:
- Cursor movement changes the active image.
- No clicking required.

Mobile:
- Swipe interaction.

The hero image and caption update together.

---

## Visual Direction

- Editorial
- Museum-like
- Layered
- Tactile
- Bold
- Strategic
- Sophisticated

---

## Avoid

- Generic portfolio cards
- Flat project sections
- Heavy shadows
- Glassmorphism
- Neon gradients
- Autoplay
- Decorative animation without purpose
